# Vision — Errata

## Problem

Mundane maintenance slips: nails, beard, bathrooms, filters, paperwork, seasonal chores. Habit apps optimize for daily streaks and identity. Generic todos don’t model “every 14 days, ~20 minutes, remind me, show what’s waiting.” Existing close options (e.g. MainTask, Loop) may not match a **duration-aware pending queue** plus personal taste — Errata exists to close that gap if needed.

## Product

A lightweight Android app where you:

1. **Pin** a recurring upkeep task  
2. Set **cadence** and **estimated duration**  
3. Get **reminders**  
4. Work from a **focused pending list** until done  
5. When time is short, open a **free window** (“I have N minutes” / “must stop by T”) and get tasks that fit  

Name **Errata** = small corrections. (UpKeep was the preferred word; taken by a CMMS on Play/trademark.)

## Cadence philosophy

- Default: **from last completion**, with **light catch-up** when badly overdue so seasons don’t drift forever  
- Users choose their destiny: per-task and global overrides for from-completion / fixed-anchor / catch-up  
- Completing late is normal — never framed as failure  

Full policy: [`03-product-map.md`](./03-product-map.md).

## Success looks like

- You trust the list on a tired morning  
- You can spend a free pocket of time without guessing what fits  
- Reminders fire without murdering battery on old hardware  
- Completing something late doesn’t feel like failure  
- Data survives app updates; export exists before any cloud fantasy  

## Non-goals (v1)

- Multi-user / family chore assignment  
- Social, coaching, XP, streaks as core loop  
- Cloud account  
- Full GTD / project management  
- Windows / desktop client  
- Medical device or treatment claims (reminders ≠ clinical care)
